What stays on your computer

DocuMind has no account and no DocuMind server. What leaves your computer depends only on the AI you choose in Settings.

Always stored only on your computer

  • The documents you add and the text extracted from them
  • Your chat history
  • Your settings, including your NVIDIA API key

Removing a document or clearing a chat deletes it from your computer.

Sent to the AI you choose

NVIDIA cloud. Fast, high-quality answers using your own free NVIDIA API key. Document text and your questions are sent to NVIDIA to index files and write answers. Needs internet.

Local AI with Ollama. The AI runs on your computer, so nothing is sent anywhere and it works offline. Needs the free Ollama app and a few GB of model downloads. Answers are slower on older computers.

Install and first launch

DocuMind isn't signed by Apple or Microsoft yet, so your computer treats it as an app from an unknown developer and asks you to confirm the first time you open it. You only do this once.

  1. Open the .dmg and drag DocuMind to Applications
  2. Try to open DocuMind once

    Double-click DocuMind in Applications. macOS says it could not verify the app. Click Done, not Move to Trash.

  3. Allow it in System Settings

    Open System Settings, then Privacy & Security, and scroll down to Security. Next to the message about DocuMind, click Open Anyway. The button appears for about an hour after you tried to open the app.

  4. Confirm with your Mac password

    Enter your password, then click Open Anyway once more. macOS remembers your choice, so from now on DocuMind opens normally.

    If there's no Open Anyway button, or macOS says DocuMind "is damaged and can't be opened", run this once in Terminal, then open DocuMind again:
    xattr -cr /Applications/DocuMind.app
  5. Choose your AI

    Settings opens on first launch. Paste an NVIDIA API key, or pick Local AI if Ollama is installed.

  1. Keep the download

    Your browser may warn that the installer isn't commonly downloaded. Choose Keep. In Edge, open the menu next to the download, choose Keep, then Keep anyway.

  2. Run the installer

    If Windows shows "Windows protected your PC", click More info, check that the app is DocuMind (the publisher shows as unknown), then click Run anyway.

    If the message says Smart App Control blocked the app and there's no Run anyway, Windows allows only signed apps on this PC and has no exception for single apps. You can turn it off in Windows Security, under App & browser control, then Smart App Control. That lowers protection for every app, so only do it if you're comfortable with that. On some Windows 11 versions it can't be turned back on without resetting Windows.
  3. Open DocuMind from the Start menu

    The first start can take up to a minute while DocuMind prepares itself.

  4. Choose your AI

    Settings opens on first launch. Paste an NVIDIA API key, or pick Local AI if Ollama is installed.

  1. Install the package, or make the AppImage runnable

    On Debian and Ubuntu: sudo apt install ./DocuMind_*.deb. On Fedora and openSUSE: sudo dnf install ./DocuMind-*.rpm. Or run the AppImage:

    chmod +x DocuMind_*.AppImage
./DocuMind_*.AppImage
    If the AppImage doesn't start or says "AppImages require FUSE to run", install FUSE 2 once, then try again:
    sudo apt install libfuse2t64   # Ubuntu 24.04 and newer
sudo apt install libfuse2      # Ubuntu 22.04
  2. Choose your AI

    Settings opens on first launch. Paste an NVIDIA API key, or pick Local AI if Ollama is installed.

Questions

Is DocuMind free?

Yes. The app is free. NVIDIA cloud AI runs on your own NVIDIA account, which sets its own usage limits. Local AI with Ollama is free and runs on your computer.

Why does my computer say DocuMind is from an unknown developer?

Apple and Microsoft show this for any app that isn't signed with a paid developer certificate, which DocuMind doesn't have yet. It doesn't mean the app is harmful. Install and first launch shows how to open it once; after that it opens normally.

How do I know the download is safe?

DocuMind's source code is public on GitHub, and every installer is built automatically by GitHub from that code, not on anyone's personal computer. The release page lists exactly which code each version was built from.

Does DocuMind need an internet connection?

With NVIDIA cloud AI, yes: questions and document text go to NVIDIA. With Local AI (Ollama), no: after the one-time downloads of Ollama and its models, DocuMind works fully offline.

Where are my documents and chats stored? Can anyone else see them?

Only on your computer, in DocuMind's data folder. There is no DocuMind account or server. Each account on a computer has its own separate DocuMind data.

Which AI should I choose?

NVIDIA cloud gives the fastest and most capable answers, especially for summaries, comparisons and code. Local AI keeps everything on your computer and works offline, but answers are simpler and slower on older machines. You can switch at any time in Settings.

How much memory does my computer need?

DocuMind itself runs on any recent computer. Local AI needs more: on 8 GB computers DocuMind uses Llama 3.2 3B, and with 16 GB or more it uses Llama 3.1 8B. It chooses for you and warns you if a setting is too heavy for your computer. NVIDIA cloud AI works on any computer.

Why aren't my scanned PDFs or photos being read?

Reading text from images needs Tesseract OCR, a free add-on. See Optional extras for the install command, then restart DocuMind.

How large can my files be?

There's no fixed limit. A 500-page PDF with a text layer is read in about a second; scanned pages take a few seconds each. Files with very large amounts of text, such as huge CSV exports, take longer to prepare.

Does removing a document delete my original file?

No. DocuMind only removes its own copy of the text. Your original files are never changed or deleted.

How do I update DocuMind?

Download the newest version from this page and install it over the old one. Your documents, chats and settings are kept. DocuMind doesn't update itself yet.

Does DocuMind work on phones or tablets?

No. It's a desktop app for macOS, Windows and Linux.

Can my team share documents in DocuMind?

Not at the moment. Each copy of DocuMind is personal and keeps its data on one computer.

How do I uninstall DocuMind?

First, to remove your documents, chats and saved API key, open DocuMind, go to Settings and choose Delete all my data. Uninstalling the app on its own leaves this data on your computer.

macOS
Drag DocuMind from Applications to the Trash.
Windows
Open Settings, then Apps, then Installed apps, find DocuMind and choose Uninstall.
Linux
Run sudo apt remove docu-mind or sudo dnf remove docu-mind, or delete the AppImage file.

If DocuMind is already uninstalled, delete its data folder instead: ~/Library/Application Support/com.documind.app on macOS, %APPDATA%\com.documind.app on Windows, or ~/.local/share/com.documind.app on Linux. Ollama and Tesseract are separate apps and are uninstalled on their own.
